# A Guide to Parley

A readable guide to the code of [Parley](https://github.com/linebender/parley), the Linebender rich text layout library: crates, pipeline, data structures, algorithms, invariants and conventions, with real numbers from small probe programs.

Read it locally:

```bash
cargo install mdbook mdbook-mermaid
mdbook serve --open
```

The probe programs that produced the numbers are in `scratch/probe` and depend on a Parley checkout at `../parley` (relative to this folder).

Code citations are pinned to Parley commit `2133d78` (main, 22 October 2026).
